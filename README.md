# What is TC To the Moon

### 🚀 Welcome to TCTM, the AI/ML interview prep hub

**[TC To the Moon (tctothemoon.com)](https://tctothemoon.com)** is a practice platform for engineers getting ready for **AI/ML interviews**. That includes frontier AI labs, NeoLabs, and AI/ML teams at big tech or top-tier quant companies.

AI interviews are no longer just LeetCode. A single loop can include **ML Foundations / Expertise**, **ML coding**, **AI system design**, and **Behavior** rounds. TCTM puts all of them in **one question bank**.

Interview answers are rarely simply right or wrong. TCTM shows you **where your answer ranks against other candidates**, then lets you study the stronger answers and do better on your next attempt.

---

### 📘 What makes TCTM different

| Feature | What you get |
|---|---|
| 🧭 **Practice for every round** | System design, ML foundations, and coding in one bank, instead of coding only. |
| ✌️ **Two answer modes for every question** | Answer quickly by picking options, or write a full solution with code or prose. |
| 🏆 **AI-judged Elo leaderboard** | Each answer is compared head-to-head against other answers by an AI judge, and every question has its own Elo ranking. |
| 💡 **Learn from top answers** | Once you've submitted, the top-ranked answers open so you can see what "great" looks like. |
| 🐍 **In-browser Python runner** | Write and run code in the browser with a starter template and visible tests. No setup needed. |
| 📚 **Interactive knowledge lessons** | 280+ lessons with interactive figures and playgrounds, each linked to the questions that test it. |
| 🎯 **Curated collections** | Start with the free **Starter Pack** and work up to the **[AI Labs RS Sprint](https://tctothemoon.com/collections/ai-labs-rs-sprint)** and **[NeoLab RE Sprint](https://tctothemoon.com/collections/neolab-re-sprint)**. |
| 🗣️ **Behavioral questions with follow-ups** *(NEW)* | The interviewer asks follow-ups about *your own* story, and you're scored against the bar for *your* level. |
